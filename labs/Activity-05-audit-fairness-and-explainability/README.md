# Activity 5 — Audit Fairness and Explainability

**Course Proposal alignment:** LU1/LU2 bridge · LO1/LO2 · K3, K4, A1, A2

**Goal:** Compute group-level fairness indicators, interpret explanations and recommend proportionate mitigations (A1, A2).

**Deliverable:** Fairness scorecard and explanation review

**Duration:** 60 minutes

## Files

- `Prompt Pack.pdf` — approved prompts and safe-use reminders.
- `checklist.md` — submission and acceptance checklist.
- `fairness-data.csv` — supplied mock input or working template.
- `explanation-samples.csv` — supplied mock input or working template.
- `fairness-scorecard.csv` — supplied mock input or working template.

## Step-by-step

1. Open fairness-data.csv and create a confusion matrix for groups A and B.
2. Compute selection rate, true-positive rate, false-positive rate and precision for each group.
3. Calculate absolute gaps and describe which error creates the most serious harm.
4. Use the fairness prompt to propose data, threshold, feature and process investigations.
5. Review explanation-samples.csv and rate each explanation for fidelity, clarity and actionability.
6. Write a recommendation with chosen metric, limitations, mitigation, owner and monitoring threshold.

## Acceptance check

The scorecard shows correct metrics by group, interprets harm cautiously and connects mitigation to an owner and monitoring rule.

## Safety and privacy

Use only supplied mock data. Do not enter personal, confidential, assessment or client information into a public AI system.

# Activity 2 — Turn Principles into an AI Code of Conduct

**Course Proposal alignment:** LU1/LU2 bridge · LO1/LO2 · K2, K4, A1, A2

**Goal:** Translate responsible AI principles into observable duties, controls and evidence (A1, A2).

**Deliverable:** AI Ethics Code of Conduct with control statements

**Duration:** 45 minutes

## Files

- `Prompt Pack.pdf` — approved prompts and safe-use reminders.
- `checklist.md` — submission and acceptance checklist.
- `principles.csv` — supplied mock input or working template.

## Step-by-step

1. Review principles.csv and choose the eight principles relevant to BrightHire.
2. Write one mandatory duty for each principle using clear 'must' language.
3. Add a preventive, detective or corrective control and name its control owner.
4. Define evidence such as an approval, test report, decision log, model card or complaint record.
5. Use the audit prompt to identify vague statements; revise any item that cannot be tested.
6. Record one exception process and one consequence for deliberate non-compliance.

## Acceptance check

Every principle has a mandatory duty, owner, control, frequency/trigger, evidence and failure indicator.

## Safety and privacy

Use only supplied mock data. Do not enter personal, confidential, assessment or client information into a public AI system.

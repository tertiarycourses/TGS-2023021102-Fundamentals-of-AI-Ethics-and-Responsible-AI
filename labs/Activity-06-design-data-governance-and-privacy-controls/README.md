# Activity 6 — Design Data Governance and Privacy Controls

**Course Proposal alignment:** LU2 · LO2 · K4, A2

**Goal:** Review AI data lineage, quality, privacy threats, access and retention controls (A2).

**Deliverable:** Data sheet, lineage map and privacy control plan

**Duration:** 45 minutes

## Files

- `Prompt Pack.pdf` — approved prompts and safe-use reminders.
- `checklist.md` — submission and acceptance checklist.
- `data-inventory.csv` — supplied mock input or working template.
- `quality-sample.csv` — supplied mock input or working template.
- `lineage.csv` — supplied mock input or working template.
- `privacy-control-plan.csv` — supplied mock input or working template.

## Step-by-step

1. Open data-inventory.csv and confirm owner, source, authority, sensitivity, purpose, location and retention.
2. Complete lineage.csv from source through transformations, training, evaluation and production decisions.
3. Measure missingness and representativeness overall and by group; record exceptions.
4. Threat-model linkage, membership inference, model inversion and prompt disclosure.
5. Select minimisation, access, encryption, k-anonymity, differential privacy or federated controls only where justified.
6. Define retention and deletion for source data, features, embeddings, logs, caches and backups.

## Acceptance check

The data plan can reconstruct provenance and sets measurable quality, access, privacy, retention and deletion requirements.

## Safety and privacy

Use only supplied mock data. Do not enter personal, confidential, assessment or client information into a public AI system.

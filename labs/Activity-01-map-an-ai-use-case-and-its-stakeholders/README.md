# Activity 1 — Map an AI Use Case and Its Stakeholders

**Course Proposal alignment:** LU1 · LO1 · K1, A1

**Goal:** Identify the system purpose, decision, stakeholders, benefits, harms and ethical tensions (A1).

**Deliverable:** Completed AI Use-Case & Stakeholder Canvas

**Duration:** 45 minutes

## Files

- `Prompt Pack.pdf` — approved prompts and safe-use reminders.
- `checklist.md` — submission and acceptance checklist.
- `scenario.md` — supplied mock input or working template.
- `stakeholder-map.csv` — supplied mock input or working template.
- `use-case-canvas.md` — supplied mock input or working template.

## Step-by-step

1. Open scenario.md and underline the AI-assisted decision, not merely the model output.
2. Complete stakeholder-map.csv with decision makers, operators, affected people and assurance actors.
3. For each affected group, record benefit, harm, severity, reversibility and current control.
4. Use Prompt 1 to test completeness; verify every suggestion against the scenario and label assumptions.
5. Use Prompt 2 to identify a power imbalance and add a feedback or contest route.
6. Write three prohibited uses and three measurable success conditions in the canvas.

## Acceptance check

The canvas names the decision, at least six stakeholders, two benefits, four harms, three prohibited uses and an accountable owner.

## Safety and privacy

Use only supplied mock data. Do not enter personal, confidential, assessment or client information into a public AI system.
